統計科 承辦人員 您好：

敝單位〔台灣綜合研究院 ○○所／○○計畫〕目前執行〔計畫名稱，例：製造部門淨零轉型相關研究〕，
需要長期追蹤我國特定產業之進出口變化，以分析歐盟碳邊境調整機制（CBAM）、東南亞水泥傾銷，
以及石化產品市場競爭對我國產業的影響。分析結果將提供政策研究與內部決策參考。

目前我們透過貴署「海關進出口統計」網站的綜合查詢（GA30）取得資料，查詢功能完整，非常感謝。
由於需要的稅號較多、須逐月更新，每次查詢都需輸入驗證碼，人工作業負擔較大，
因此想請教是否有較適合的取得方式：

**一、所需資料範圍**

1. 期間：民國 108 年 1 月起，按月，並持續每月更新。
2. 貨品：11 碼稅號（CCC Code），範圍大致為第 25、28、29、31、38、39、40、72、73、76 章，
   以及 2601、2710、2711、2716、2804 等稅則號別（約 3,000 至 3,500 個稅號）。
3. 國家別：全部國家（地區）。
4. 進出口別：進口總值（含復進口）、出口總值（含復出口）。
5. 統計值：金額（美元）、重量（公斤）、數量與數量單位。

**二、想請教的問題**

1. 貴署是否提供 API 或免驗證碼的批次下載管道（例如每月全稅號 × 國家別的整批檔），供研究單位定期取得？
2. 「進出口貿易統計資料訂購」是否涵蓋上述範圍（11 碼 × 國家別 × 月）？是否提供電子檔（CSV／Excel）
   或線上下載？可否只訂購部分章別、或一次訂購歷史期間（108 年迄今）？費用如何計算？
3. 學術或政策研究用途是否有優惠或專案申請方式？
4. 若使用者以貴署資料加工後，於內部或對外網站以圖表、彙總指標呈現（非原始資料轉售），是否符合使用規範？
   需要標註哪些出處文字？
5. 若仍以綜合查詢取得，單次查詢可輸入的稅號數量或結果筆數是否有上限？

如需進一步說明用途或資料範圍，歡迎與我們聯繫。感謝撥冗協助！
